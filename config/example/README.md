# Configuración de ejemplo

Estos archivos están versionados y **no tienen datos reales**. Para usarlos, copiá los que
necesites a `config/local/` (esa carpeta está ignorada por git) y completalos.

- `cameras.yaml` — cámaras y canales del NVR (se agrega en la fase F1).

Las zonas, mesas, umbrales y el plano del salón **no** van acá: se editan desde el dashboard
y se guardan en la base (con export/import a YAML para backup).
